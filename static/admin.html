Configuración rclone
Ver instrucciones para conectar Google Drive
1. Instala rclone:
curl https://rclone.org/install.sh | sudo bash

2. Configura Google Drive:
rclone config

3. Elige: n (New remote)
4. Nombre: gdrive
5. Tipo: drive (Google Drive)
6. Sigue los pasos → abre el navegador
7. Inicia sesión con tu Gmail → Permitir
8. Listo. ZERO usará gdrive:ZERO_BACKUP/
